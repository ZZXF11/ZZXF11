### 🔬 关于我

我目前是**华南理工大学博士生**，师从[金连文教授](http://dlvc-lab.net/lianwen/)，所在实验室为[深度学习与视觉计算实验室](https://github.com/SCUT-DLVCLab)。

我的研究方向包括**文档智能、计算机视觉与多模态学习**，目前重点关注：

- **多模态 OCR 大模型**：复杂视觉文档的识别与理解。
- **AIGC**：视觉文本生成、编辑与文档内容创作。
- **文档修复**：历史文档文字内容与视觉外观的恢复。
